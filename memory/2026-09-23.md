### 补丁机制（重要约定）

- PyStudio 有 bug → 修复代码必须放进 `/* USER CODE BEGIN xxx */ ... /* USER CODE END xxx */` **保护区**，这样新手在 PyStudio 点"重新生成代码"后补丁会被原样保留。
- 模板里共 2 处补丁，均在保护区内：
  1. `Core/SRC/rcc.c` 的 `Studio_RCC_Init 1`：`NVIC_SetPriority(SysTick_IRQn, (1UL<<__NVIC_PRIO_BITS)-1)` + `SysTick->CTRL |= SysTick_CTRL_TICKINT_Msk`。原因：Puya 的 `LL_InitTick()` 漏了置位 TICKINT（ST 原版有），不补则 SysTick 中断不开、`uwTick`/`BSP_GetTick()` 恒为 0。
